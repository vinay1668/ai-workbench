# Evaluate a prompt or skill

“Looks impressive” and “saves work reliably” are different claims. Use a small comparison before making a resource part of your routine.

1. Pick three representative tasks using public or invented inputs.
2. Record the assistant, model if known, tools, settings, and date.
3. Try a clear baseline prompt and the proposed pack under comparable conditions.
4. Judge the outputs against the same rubric. If feasible, hide which version produced which output.
5. Record completion, important defects, manual corrections, time, and cost if observable.
6. Repeat an important case if a one-off result could change your decision.
7. Keep useful changes and record where the procedure fails.
