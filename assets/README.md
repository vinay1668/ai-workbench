# README artwork

The banner, category cards, and workflow animation are original programmatic artwork for AI Workbench. They contain no screenshots, private files, downloaded brand assets, analytics, or external image requests.

- `banner.png`: static introduction, 1280 × 560.
- `card-*.svg`: six scalable links to resource categories.
- `workflow.gif`: five slowly highlighted stages, with no flashing or rapid motion.
- `workflow-static.png`: a static alternative with the same full workflow.

Regenerate with `python3 scripts/make_assets.py` after installing Pillow in your own environment. All artwork is covered by the repository's MIT license. Fonts are loaded from common system locations during rendering and are not bundled.
