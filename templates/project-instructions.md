# Project instructions template

This file is a template, not an active instruction file. Adapt it to your project and use the instruction mechanism supported by your coding agent.

```text
Project purpose: [one sentence]
Architecture: [relevant directories and responsibilities]
Stack: [actual framework, runtime, package manager]

Setup command: [verified command]
Development command: [verified command]
Build command: [verified command]
Relevant test commands: [verified commands and what they cover]

Conventions: [existing patterns worth preserving]
Boundaries: [generated files, migrations, external services]
Definition of done: [observable behavior and appropriate checks]

Use synthetic fixtures. Keep credentials and private data out of source,
logs, screenshots, commits, and issue text. Do not read unrelated personal
files. Do not publish, send messages, or connect accounts without task scope.

Report the work performed, verification actually completed, and limitations.
```

Keep this short and factual. Replace sample commands with commands you have verified in the target repository. Do not fill it with conflicting generic advice.
